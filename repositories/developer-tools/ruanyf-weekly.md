## 한 줄 요약

ruanyf/weekly는 기술 기사·소프트웨어·학습 자원을 중국어로 소개하고 호별로 보관하는 ‘科技爱好者周刊’의 공개 저장소이다.[1][2]

## 이 Repository는 무엇인가?

프로그램을 설치해 쓰는 제품이 아니라, 매주 공유할 만한 기술 내용을 정리하는 읽기 중심의 간행물이다.[1]

README는 금요일 발행을 안내하며, 독자가 글·소프트웨어·자료를 GitHub Issue로 제안하도록 연결한다.[1]

### 자료 확인 범위

2026-09-27에 공개 README와 아래에 인용한 공식 파일을 확인한 기본 초안이다.
설치·실행 시험이나 성능 검증을 한 문서는 아니다.
개인적인 Star 이유와 평가, 사용 후기는 직접 작성할 수 있도록 비워두었다.

## 주요 기능

- 연도와 월 아래에 호수·제목·본문 링크를 배열하여 과거 글을 시간순으로 찾아볼 수 있다.[1]
- 대표 글인 413호에는 기술 동향, 기사, 도구, 자원, 이미지, 발췌문, 인용문 등 서로 다른 성격의 읽을거리가 구분되어 있다.[2]
- 소개 항목에 원문이나 프로젝트 링크를 붙이고 일부 항목에는 제보자와 해당 Issue도 표시한다.[2]

## 어떻게 동작하는가?

```text
README에서 관심 있는 연도·월·호수 선택.
↓
해당 Markdown 본문에서 해설과 분야별 링크 탐색.
↓
관심 항목의 원문·도구 저장소 또는 과거 호수로 이동.
```

이 흐름은 독자가 문서를 탐색하는 과정이며, 자료를 자동 수집하거나 프로그램을 실행하는 처리 흐름을 뜻하지 않는다.[1][2]

### 확인한 파일 구성

- `README.md`는 간행물 소개, 제보 경로, 연도별·월별 목차를 모은 시작점이다.[1]
- `docs/issue-413.md`는 개별 호의 실제 본문으로, 대표 논평과 분류된 자료 소개, 과거 글 링크를 함께 담는다.[2]

## 어떤 기술을 사용하는가?

- `Markdown`: 제목·목록·인용·이미지·링크로 주간 기사와 목차를 표현하는 문서 형식이다.[1][2]
- `GitHub Issues`: 독자가 기사나 소프트웨어를 제안하는 공개 창구이며, 별도 구인 게시물도 README에서 안내한다.[1]

## 실제로 어디에 사용할 수 있는가?

- 개인 기술 독서에서 관심 호수를 고른 뒤 원문 기사와 도구를 찾아가는 자료 탐색의 출발점으로 활용할 수 있다.[1][2]
- 413호의 기사·도구·자원 분류를 살펴보며 기술 링크에 짧은 설명과 출처를 붙이는 큐레이션 문서의 구성을 학습할 수 있다.[2]

## 왜 주목할 만한가?

학습 관점에서는 README가 긴 본문을 모두 담는 대신 시간별 색인을 제공하고, 각 호가 해설과 외부 자료의 연결을 맡는 문서 분리가 관찰된다.[1][2]

## 장점

- 호수별 고유 파일과 목차 링크가 있어 특정 시기의 글을 다시 찾아 읽는 경로가 명확하다.[1]
- 대표 호는 짧은 소개와 원문 링크를 함께 제공하므로 요약을 읽은 뒤 원래 자료로 넘어갈 수 있다.[2]

## 단점 / 주의점

- 본문은 중국어 중심이며, 소개문에는 작성자의 논평과 외부 자료의 요약이 함께 있으므로 둘을 같은 종류의 사실로 읽지 않아야 한다.[2]
- 금요일 발행 안내와 별개로 413호에는 연휴 휴간 공지가 있어 매주 발행이 예외 없이 보장되는 것은 아니다.[1][2]
- 확인한 README와 대표 글만으로 외부 링크 대상 자료의 최신 상태나 재배포 조건까지 보장할 수 없다.[1][2]
