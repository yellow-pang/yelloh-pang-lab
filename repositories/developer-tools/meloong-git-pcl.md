## 한 줄 요약

PCL은 Minecraft용 Plain Craft Launcher의 공개 소스 저장소다.
README는 UI 라이브러리, 애니메이션, 다운로드, 게임 실행 모듈 등 대부분의 소스를 포함한다고 설명한다.
게임 자체나 모든 부분이 공개된 완전한 개발 원본이라고 단정해서는 안 된다.[1]

## 게임 실행 버튼 뒤의 준비 작업

게임을 시작하려면 선택한 버전, 필요한 파일, Java 실행 환경과 로그인 상태가 서로 맞아야 한다.
런처는 이런 준비를 사용자가 각각 처리하는 대신 한 흐름으로 연결하는 역할을 한다.
README는 코드가 실시간 동기화되지 않고 PCL 릴리스 때 갱신된다고 명시한다.[1]

따라서 저장소의 변경 시점만으로 실제 배포 프로그램의 모든 최신 동작을 판단할 수는 없다.
릴리스와 공개 코드의 대응 관계를 확인하는 것이 기능 이름을 나열하는 것보다 먼저다.

## 실제 실행 흐름을 보여 주는 파일

`Plain Craft Launcher 2/Modules/Minecraft/ModLaunch.vb`의 `McLaunchStart()`는 UI 스레드에서 호출되는지 검사한다.
이미 게임 실행이 진행 중이면 중복 시작을 막고, 강제로 지정한 인스턴스가 있으면 존재와 오류 상태를 확인한다.
인스턴스는 여기서 선택한 게임 버전과 그 설정 묶음으로 이해할 수 있다.[2]

실제 로더는 사전 검사를 한 뒤 Java 확보, 로그인, 부족한 파일 보완, 실행 인자 구성, 파일 압축 해제 등을 작업 목록에 넣는다.
이후 사전 처리와 사용자 정의 명령, 프로세스 시작, 게임 창 대기, 종료 처리를 연결한다.
진행 비중과 일부 병행 여부도 작업 속성으로 지정되므로 실행 버튼은 단일 프로그램 호출보다 복잡한 조정 지점이다.[2]

`McLaunchOptions`에는 서버 주소, 지정할 인스턴스, 추가 인자, 실행 스크립트를 저장하는 옵션이 있다.
스크립트 저장 옵션은 실제 실행을 취소하는 동작까지 설명되어 있어, 스크립트 생성 성공과 게임 실행 성공을 나누어 볼 수 있다.[2]

## 가상 예시: 특정 버전으로 실행하기

다음은 게임을 설치하거나 로그인한 실제 경험이 아닌 코드 이해용 예시다.
이미 준비된 개인 게임 인스턴스를 고른 뒤 실행을 요청한다고 가정한다.
런처는 중복 실행 준비와 인스턴스 상태를 확인하고, Java와 파일·로그인을 준비하는 단계로 넘어간다.[2]

파일 보완에서 멈춘다면 게임 화면 렌더링 문제와는 다른 단계의 실패다.
프로세스가 시작되었더라도 창을 기다리는 단계가 별도로 있으므로, 프로세스 생성만으로 사용 준비가 끝났다고 판단하면 안 된다.[2]
이 구분은 사용자 지원 로그를 읽거나 실행 파이프라인을 학습할 때 유용하다.

## 공개 소스와 자유로운 재배포는 다르다

`LICENCE`는 일반적인 MIT·Apache 라이선스가 아니라 PCL 제한 배포 허가 링크와 합리적 사용 지침을 담고 있다.
지침 자체는 법적 문서나 계약이 아니라고 명시하며, 명시적으로 부여하지 않은 권리는 보유한다고 설명한다.[3]

일부 참고와 기능이 겹치는 대규모 재사용을 구분하고, 후자에는 제3자 수정판 표시·이름·출처·소스 공개 등의 조건을 적는다.
Minecraft 실행 기능이 있으면 구매·후원 안내에 관한 조건도 있고 Windows의 후원 해금 기능과 유사한 표현을 제한한다.
연결된 제한 배포 허가 본문까지 이번 조사에서 검증한 것은 아니므로 포크 배포나 재구현 전 원문 확인이 필요하다.[3]
사용자 정의 명령 실행 단계도 있으므로 가져온 설정을 무조건 안전한 데이터로 보아서는 안 된다.[2]

## 직접 읽어볼 자료

- README의 공개 범위와 릴리스 동기화 설명부터 읽는다.[1]
- `ModLaunch.vb`의 공개 `McLaunchStart()` 다음에 로더용 동명 메서드를 읽으면 검사와 준비 단계가 이어진다.[2]
- `LICENCE`에서 가벼운 참고와 대규모 재사용의 구분을 확인하고 연결된 배포 허가를 별도로 검토한다.[3]

## 정리

PCL은 게임 실행에 필요한 준비와 진행 상태를 조정하는 런처의 구조를 보여 준다.
소스 열람 가능성, 완전한 소스 공개 여부, 수정판 배포 허용 범위는 각각 별개의 문제다.[1][2][3]
