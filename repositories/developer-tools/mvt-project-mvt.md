## 한 줄 요약

Mobile Verification Toolkit(MVT)은 Android·iOS 기기의 침해 가능성을 조사할 때 디지털 흔적의 수집·분석을 돕는 포렌식 도구 모음이다.[1]

## 이 Repository는 무엇인가?

포렌식은 기기에서 남은 기록을 조사하는 분석 작업이며, MVT는 스파이웨어 감염 가능성을 살피는 흔적 수집을 단순화·자동화하는 목적을 가진다.[1]

일반 사용자의 자가 안전 진단용 앱이 아니라, 디지털 포렌식과 명령행 도구를 이해하는 기술자·조사자를 대상으로 한다.[1]

### 자료 확인 범위

2026-09-27에 공개 README와 아래에 인용한 공식 파일을 확인한 기본 초안이다.

개인적인 Star 이유와 평가, 사용 후기는 직접 작성할 수 있도록 비워두었다.

## 주요 기능

- Android와 iOS에서 확보한 자료를 플랫폼별 명령으로 분석하고, 공통 명령에는 버전·플러그인·침해 지표 관리 기능을 둔다.[1]
- IOC는 알려진 침해를 의심할 단서인 침해 지표이며, 공개 IOC를 이용해 알려진 스파이웨어 캠페인의 흔적을 찾는 기능을 지원한다.[1]
- 플러그인 패키지로 포렌식 분석 모듈과 공통·플랫폼별 최상위 명령을 확장할 수 있다.[1]

## 어떻게 동작하는가?

```text
자료 소유자의 명시적 동의와 허가 범위 아래 조사 자료를 준비한다.
↓
플랫폼에 맞는 분석 기능과 관련 침해 지표로 흔적을 조사한다.
↓
조사자가 분석 결과와 지표의 한계를 함께 해석한다.
```

이 흐름은 동의를 전제로 한 분석 개념만 설명하며, 지표가 검출되지 않았다는 결과가 기기의 무감염을 증명하지는 않는다.[1][2]

### 확인한 파일 구성

- `pyproject.toml`은 패키지 의존성과 Python 요구사항을 선언하고, `mvt`, `mvt-ios`, `mvt-android`를 각각 공통·플랫폼별 모듈 진입점에 연결한다.[3]
- 같은 manifest는 `src`를 Python 패키지 탐색 위치로 지정하고, `tests`를 테스트 대상 경로로 설정한다.[3]
- `LICENSE`는 MVT License 1.1의 전문이며, 자료 소유자 동의와 배포 시 책임을 규정한다.[2]

## 어떤 기술을 사용하는가?

- `Python`: 분석 도구의 구현·배포 언어이며 manifest는 Python 3.10 이상을 요구한다.[3]
- `setuptools·setuptools-scm`: 패키지 빌드와 버전 산정에 사용하며, manifest는 Git의 버전 태그를 기준으로 버전을 얻도록 설정한다.[3]
- `IOC`: 공개된 공격 흔적 정보를 분석 입력으로 활용하지만, 알려지지 않은 흔적까지 포괄하는 보장은 없다.[1]

## 실제로 어디에 사용할 수 있는가?

- 명시적으로 동의받은 자료를 대상으로 모바일 포렌식의 지표 대조와 결과 해석 개념을 학습하는 사례에 해당한다.[1][2]
- 공통 명령과 운영체제별 분석을 나누고 플러그인으로 확장하는 명령행 도구의 구성을 읽는 데 활용할 수 있다.[1][3]

## 왜 주목할 만한가?

학습 관점에서는 탐지 기능만큼 공개 지표의 불완전성과 동의 요건을 제품 설명의 핵심 경계로 제시한다는 점이 중요하다.[1][2]

## 장점

- Android·iOS 분석과 공통 관리 기능을 구분하여 자료 유형에 따른 진입점을 제공한다.[1][3]
- 기본 모듈 외에 추가 분석과 명령을 연결할 플러그인 확장 경로를 문서화한다.[1]

## 단점 / 주의점

- 공개 IOC만으로는 최근 흔적을 놓칠 수 있고, 포괄적 분석에는 비공개 지표·연구·위협 정보가 필요하다고 경고한다.[1]
- MVT License는 강요 없는 자료 소유자의 명시적 동의를 요구하고, 절차·개인정보 영향·자료 보관과 폐기 방침을 충분히 알리도록 규정한다.[2]
- README는 v3 병합으로 출력에 호환성 변경이 발생했음을 알리므로, 기존 결과 처리 스크립트가 그대로 동작한다고 가정해서는 안 된다.[1]
