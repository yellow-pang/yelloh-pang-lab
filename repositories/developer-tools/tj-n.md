## 한 줄 요약

n은 여러 Node.js 버전을 내려받아 보관하고 사용할 버전을 명령이나 목록에서 선택하는 버전 관리 도구이다.[1]

## 이 Repository는 무엇인가?

Bash 스크립트로 작성되었지만 사용자의 명령행 셸 자체를 Bash로 바꿀 필요는 없다.[1]

미리 빌드된 Node.js를 공통 설치 경로에 복사해 활성 버전을 교체하며, 다운로드 사본은 다시 쓰도록 별도 캐시에 보관한다.[1]

## 주요 기능

- 버전 번호, 장기 지원판을 뜻하는 `lts`, 최신판 표시를 받아 설치하거나 대화형 목록에서 저장된 버전을 고를 수 있다.[1]
- `auto`는 현재·상위 폴더의 버전 지정 파일을 읽고, `engine`은 `package.json`의 호환 버전 조건을 확인한다.[1]
- `run`과 `exec`로 저장된 버전을 활성 설치 변경 없이 이용하고, 캐시 조회·정리와 오프라인 사용도 지원한다.[1]

## 어떻게 동작하는가?

```text
사용할 버전이나 버전 지정 파일을 선택한다.
↓
필요한 바이너리를 다운로드하거나 캐시에서 가져와 지정된 공통 경로에 설치한다.
↓
해당 경로의 Node.js를 사용하며, 이전 다운로드 사본은 후속 전환에 재사용한다.
```

기본 설치 흐름은 기존 활성 버전을 덮어쓰는 방식이며, 저장된 특정 버전을 일회성으로 쓰는 `run`·`exec`와 구별된다.[1]

### 확인한 파일 구성

- `bin/n`은 Bash 실행 파일이며 설치 경로·캐시 경로·다운로드 주소와 통신 옵션을 설정한다.[2]
- `package.json`은 `n` 명령을 `bin/n`에 연결하고 해당 파일을 배포 대상으로 지정한다.[3]
- 패키지의 테스트 명령은 `test/bin/run-all-tests`이며 개발 의존성에 Bash 테스트 도구인 Bats 관련 패키지가 선언되어 있다.[3]

## 어떤 기술을 사용하는가?

- `Bash`: 다운로드와 버전 선택·활성화 기능을 구현하는 스크립트 언어이다.[1][2]
- `npm`: 이미 Node.js가 있는 환경에서 이 도구를 전역 설치하는 경로를 제공한다.[1][3]
- `curl·wget`: 구현에 다운로드 요청 옵션이 준비되어 있는 외부 통신 도구이다.[2]

## 실제로 어디에 사용할 수 있는가?

- 개인 학습 프로젝트의 버전 파일에 맞춰 Node.js를 선택하고 지원판을 바꿔 가며 동작을 비교할 수 있다.[1]
- 여러 버전을 캐시에 보관한 뒤 네트워크 없이 재설치하거나 특정 버전으로 한 명령만 실행하는 용도로 쓸 수 있다.[1]

## 왜 주목할 만한가?

학습 관점에서는 다운로드 보관 위치와 현재 활성 버전 설치 위치를 나누고, 활성화와 일회성 실행을 다른 명령으로 제공하는 점이 관찰점이다.[1]

## 장점

- 대화형 선택과 명시적인 버전 지정 명령을 모두 제공한다.[1]
- 설치 경로·캐시 경로·다운로드 미러와 CPU 아키텍처 선택을 환경 변수나 옵션으로 조절할 수 있다.[1]

## 단점 / 주의점

- macOS·Linux·WSL 등 유닉스 계열을 지원하지만 네이티브 Windows 셸, Git for Windows Bash와 Cygwin은 지원하지 않는다.[1]
- 기본 경로인 `/usr/local`은 쓰기 권한 문제가 생길 수 있고 다른 Node.js 설치가 PATH에서 앞서면 설치한 버전과 실제 실행 버전이 다를 수 있다.[1]
- `engine` 처리는 `jq` 또는 `node`가 필요하고 복잡한 버전 범위에는 `npx semver`를 쓰며, 프로젝트 라이선스는 MIT이다.[1][3]
