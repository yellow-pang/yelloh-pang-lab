## 하나의 프로그램보다 안내 자료의 입구

`bannedbook/fanqiang`은 인터넷 접근 도구와 사용 안내를 운영체제·장치별로 모은 중국어 중심 자료 저장소다.
루트 README는 Windows, Android, iOS, macOS, 라우터, Linux, 게임기 자료를 연결하고, 브라우저 묶음과 뉴스 앱도 소개한다.
따라서 이름 하나의 단일 VPN 엔진이나 모든 도구를 같은 개발자가 만든 통합 제품으로 설명하는 것은 부정확하다.[1]

이 자료를 읽는 출발점은 '접속이 된다'는 한 문장 안에 여러 조건이 섞여 있다는 점이다.
어떤 장치에서 어떤 클라이언트를 쓰는지, 통신을 중계할 서버 정보가 있는지, 브라우저만 연결할지 특정 앱이 자료를 받아 저장할지에 따라 살펴볼 문서가 달라진다.
README의 분류는 이런 경로를 찾아가는 목차 역할을 한다.
안내에 실린 도구 이름만 모으기보다 항목의 역할부터 나누어야 한다.[1]

프록시는 요청을 중간 서버를 통해 전달하는 방식이고, VPN은 별도의 가상 네트워크 연결을 만드는 기술을 가리킨다.
문서에서 두 종류의 표현을 접하더라도 모두 동일한 범위의 통신을 처리한다고 이해하면 안 된다.
여기서는 연결 방법을 실제로 실행하는 매뉴얼 대신, 저장소가 제공하는 자료의 구성과 한 대표 앱의 데이터 흐름을 설명한다.

## 목차, 묶음 배포, 개별 앱의 차이

루트의 운영체제별 절에는 여러 외부 프로그램에 관한 안내가 섞여 있다.
자료 저장소의 공식 README라는 것은 이 목차와 설명의 출처가 명확하다는 뜻이지, 여기에 연결된 모든 외부 프로그램의 원저자 문서라는 뜻은 아니다.
각 링크를 따라갈 때 프로그램 개발 주체와 이 저장소의 안내 작성 주체를 구분해야 한다.
이 조사에서는 링크된 전체 도구의 동작이나 배포 파일의 안전성을 확인하지 않았다.[1]

ChromeGo 절은 여러 도구를 묶고 무료 서버 정보를 포함한다고 설명하지만, 지역·통신사·차단 상황에 따라 효과가 다르다고도 적는다.
따라서 저장소에 배포 안내가 있다는 사실을 현재의 가용성이나 지속적인 접속 보장으로 옮겨 쓰면 안 된다.
다운로드 경로와 사용 설명이 있는 것, 서버가 신뢰할 수 있고 지금 연결되는 것은 각각 다른 확인 사항이다.[1]

대표 항목으로 추가 열람한 `fqnews2/README.md`는 FQNews2를 Android 뉴스 앱으로 소개한다.
RSS/FEED를 추가하고 중계 노드 정보를 제공하면 앱이 백그라운드에서 뉴스를 다운로드해 기기에 캐시한다고 설명한다.
RSS는 사이트의 새 글 목록을 정해진 형식으로 전달하는 방식이고, 캐시는 다음에 읽기 위해 받은 내용을 로컬에 남기는 저장이다.
이 항목은 전체 기기의 모든 통신을 대신하는 기능보다 뉴스 수집과 읽기에 초점이 있다.[2]

FQNews2 문서는 노드 정보가 있어야 정상 동작한다고 명시하고, 기반 프로젝트로 `v2ray.vpn`과 `Feeder`를 밝힌다. 'VPN 없이'라는 소개 문구가 있어도 외부 중계 설정이 전혀 필요 없다는 뜻으로 읽으면 뒤의 조건과 충돌한다.
여기서 중요한 구별은 별도 VPN 앱을 앞에 두는지 여부와 FQNews 앱 자체에 필요한 연결 정보의 존재다.
지원 형식이 나열되어 있다는 사실도 특정 제공자의 계정이나 서버가 안전하다는 증명은 아니다.[2]

## 예시로 따라가는 흐름

자료 모음의 사례는 설치 명령을 따라 하는 대신 대표 항목의 읽기 경로로 잡을 수 있다.
Android에서 공개 뉴스 피드를 읽으려는 독자는 루트 README의 FQNews 항목을 찾고, 이어 `fqnews2/README.md`로 이동한다.
여기서 입력을 두 종류로 나누어 적어 본다.
하나는 읽을 뉴스의 RSS/FEED이고, 다른 하나는 앱이 자료에 도달할 때 사용할 중계 노드 정보다.
서로 목적이 다르므로 피드 주소만 추가한 상태와 연결 조건이 갖춰진 상태를 같은 것으로 보아서는 안 된다.[1][2]

문서가 설명하는 처리는 앱의 백그라운드 다운로드와 기기 내 캐시다.
결과는 받아 둔 뉴스 자료를 로컬에서 읽을 수 있도록 하는 흐름이다.
그러나 문서에는 실제 단말의 다운로드 성공 기록이나 모든 피드의 본문 처리 결과가 제시되어 있지 않으므로, 이 글도 특정 기기에서 성공했다고 쓰지 않는다.
앱을 설치하거나 노드 정보를 가져와 연결하지 않았다.[2]

사람이 확인할 항목은 원하는 피드의 출처와 이용 조건, 설정한 중계 서비스의 운영 주체, 캐시에 남을 내용, 자료가 마지막으로 갱신된 시점이다.
이 중 로컬 캐시가 있다는 설명은 공식 문서에 있지만 캐시 삭제·암호화 방식까지 이 README만으로 알 수는 없다.
따라서 다운로드가 가능하다는 기능 설명과 익명성·기밀성의 보장을 분리해야 한다.
이 읽기 경로의 최종 산출물은 접속 성공 화면이 아니라 입력 조건, 처리 위치, 미확인 보안 항목을 나눈 이해다.[2]

## 접근 도구와 안전 보장은 같은 말이 아니다

루트 자료는 네트워크 상황에 따라 효과가 달라진다고 스스로 설명한다.
차단 회피나 중계 기능을 소개한다고 해서 모든 관찰 주체로부터 사용자를 숨기거나 모든 콘텐츠를 안전하게 만든다고 볼 근거는 없다.
무료 노드와 묶음 프로그램을 사용할 때에도 전달 경로와 배포 출처를 각각 검토해야 한다.
이 글은 허가되지 않은 네트워크 접근이나 타인의 시스템 침해를 위한 절차를 제공하지 않으며, 관련 지역의 법률과 자신이 이용하는 네트워크의 규칙을 확인하는 범위로 한정한다.[1]

또한 루트 README에는 자유롭게 배포하되 상업적으로 사용하지 말라는 문구가 있다.
반면 FQNews2는 GPLv3 기반 공개 앱이라고 별도 표기한다.
서로 다른 구성 요소의 설명을 하나의 통일된 라이선스로 정리할 수 없다는 뜻이다.
코드, 문서, 배포 묶음, 포함된 외부 도구의 재사용 조건은 각 대상에서 확인해야 하고, 루트의 짧은 문구만으로 자세한 권리 관계가 모두 해결되었다고 볼 수 없다.[1][2]

자료의 범위가 넓다는 점도 읽을 때의 제약이다.
오래된 안내, 외부 링크, 실제 소스가 포함된 하위 앱이 같은 목차에 있으므로 글의 존재만으로 최신 상태를 판단하기 어렵다.
이 조사에서는 FQNews2를 대표 항목으로 골랐으며 나머지 운영체제별 문서의 현재 정확성이나 묶음 파일의 무결성을 검증했다는 주장을 하지 않는다.

## 정리

fanqiang은 접근 도구를 찾아 읽는 자료의 집합이며 FQNews2는 그 안의 뉴스 수집 앱 사례다.
목차의 폭, 실제 연결 가능성, 통신의 안전성, 재배포 권리는 별도로 확인해야 한다.[1][2]
