## 한 줄 요약

Jasna는 영상과 이미지의 모자이크 영역을 찾아 복원하는 GUI·명령행 도구다.
일반적인 모든 영상 손상을 고치는 도구라기보다 특정 영역의 검출과 복원에 초점을 둔다.
README는 무료 BasicVSR++와 후원자용 LTX 등 모델 경로를 구분한다.[1]

## 한 프레임보다 시간상의 연결이 중요하다

영상에서 같은 영역이 여러 프레임에 이어 나타나더라도 검출은 잠시 끊기거나 잘못 잡힐 수 있다.
Jasna는 선택 영역 편집, 미리보기, 실시간 재생과 파일 출력 등 사용 경로를 제공한다.
결과가 자연스럽게 보이는지와 원래 세부 정보를 정확히 알아냈는지는 서로 다른 판단이다.
모자이크에서 생성한 디테일을 실제 원본의 증거로 취급해서는 안 된다.[1]

루트의 `jasna/`에 구현, `docs/en/`에 사용 문서, `model_weights/`에 모델 관련 영역이 있다.
`docs/en/advanced_processing.md`를 보면 복원 모델 외에도 검출 안정화와 장면 경계가 품질에 영향을 준다.
`--max-detection-gap`은 같은 위치의 짧은 검출 공백을 메우고 `--min-detection-duration`은 너무 짧은 검출을 제거한다.
값을 크게 하면 진짜 짧은 모자이크도 영향을 받을 수 있어 문서는 작게 유지하라고 안내한다.[2]

장면 전환 검출은 다른 장면을 하나의 복원 클립으로 섞지 않도록 하드 컷에서 클립을 끝낸다.
노이즈 제거는 복원 영역에 적용하며 LTX에는 사용하지 않는다고 구분한다.
즉 이름이 비슷한 후처리 옵션이라도 모든 모델에 동일하게 적용되는 것은 아니다.[2]

## 가상 시나리오: 권한이 있는 테스트 영상

직접 만든 비민감 테스트 영상에 모자이크를 넣고 복원 동작을 비교하는 상황을 가정한다.
원본은 따로 보관하고 복사본의 일부 구간만 선택한 다음 검출 결과와 장면 경계를 먼저 확인한다.
복원 모델을 고르고 짧은 구간을 출력해, 깜박임·경계 이음새·원본과의 차이를 비교할 수 있다.[1][2]

전체 영상에 적용하기 전에 장면이 바뀌는 지점에서 이전 장면의 특징이 섞이지 않는지 살펴본다.
이 예시는 결과 검증 방식을 설명한 것이며 복원 실행이나 품질 측정을 수행한 기록이 아니다.
타인이 의도적으로 가린 신체·신원 정보를 복원하는 사용은 피하고 권한과 동의가 있는 자료에 한정해야 한다.

## 하드웨어와 출력 옵션의 실제 제약

README는 NVIDIA 장치 요구와 실험적 AMD 지원, 영문 경로와 로컬 디스크 조건을 명시한다.
첫 모델 준비는 오래 걸릴 수 있고 LTX는 별도 메모리 요구가 있으므로 단순 Python 설치만으로 준비가 끝나지 않는다.[1]
`--fmp4`는 처리 도중 재생할 수 있는 출력이지만 컨테이너와 선택 구간·스트리밍 사용에 제한이 있다.
완료 후 종료·사용자 명령 옵션도 있으며 CLI의 종료는 즉시 수행된다고 안내한다.
따라서 복원 명령의 출력 파일뿐 아니라 후속 행동 옵션도 확인해야 한다.[2]

## 공개 코드와 후원자 배포물을 구분하기

공개 앱 소스의 기본 조건은 AGPL-3.0-only지만 개별 파일과 외부 모델에는 다른 조건이 있다.
LTX 관련 코드·가중치는 LTX-2.x Community License, 일부 외부 구성은 Apache-2.0 등으로 구분된다.
공식 실행 파일에는 공개 소스가 없는 후원자 보호 구성 요소가 포함될 수 있고, 암호화된 후원자 모델에는 별도 독점 조건이 적용된다.
공개 저장소만으로 공식 후원자 실행 파일을 비트 단위로 재현할 수 없다는 점도 명시한다.[3]
