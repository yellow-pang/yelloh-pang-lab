## 한 줄 요약

WeKnora는 문서를 지식 기반으로 모아 AI 질의응답, 여러 단계의 도구 작업, 연결된 위키 생성에 사용하는 지식 관리 프레임워크이다.[1]

## 이 Repository는 무엇인가?

RAG는 먼저 관련 자료를 검색한 뒤 그 내용을 참고해 답변을 생성하는 방식이며, WeKnora는 문서 이해·의미 검색·추론을 이 흐름에 연결한다.[1]

검색 기반 질의응답, Agent 작업, 자동 위키가 서로 별개 자료를 쓰는 대신 같은 지식 기반을 공유한다.[1]

### 자료 확인 범위

2026-09-27에 공개 README와 아래에 인용한 공식 파일을 확인한 기본 초안이다.
설치·실행 시험이나 성능 검증을 한 문서는 아니다.
개인적인 Star 이유와 평가, 사용 후기는 직접 작성할 수 있도록 비워두었다.

## 주요 기능

- PDF, 문서, 표, 이미지 등을 처리하고 키워드와 의미 기반 검색을 결합해 출처가 표시된 답변을 제공한다.[1]
- Agent 모드는 문서 읽기와 검색, 외부 도구 및 Skill 호출을 여러 단계로 수행하고 진행 내용을 대화에 표시한다.[1]
- Wiki 모드는 자료에서 개념을 추출해 서로 연결된 페이지와 관계 그래프를 만들고 수정 이력 비교·되돌리기를 지원한다.[1]

## 어떻게 동작하는가?

```text
모델과 저장소를 설정하고 문서를 올리거나 지원되는 데이터 원본을 연결한다.
↓
문서를 해석하고 검색용 수치 표현으로 바꾼 뒤 관련 자료를 검색하여 언어 모델에 전달한다.
↓
선택한 모드에 따라 출처 포함 답변, 도구 작업의 결과물 또는 위키 페이지를 얻는다.
```

문서 해석부터 검색·답변 생성까지 모듈식 처리 단계로 구성하며, 외부 도구 실행과 위키 생성에는 해당 모드와 연결 설정이 추가로 필요하다.[1]

### 확인한 파일 구성

- `go.mod`는 WeKnora 모듈과 Go 버전, 데이터베이스·검색·MCP 관련 의존성을 선언한다.[2]
- `cli/`는 공식 API용 명령줄 인터페이스이며 README는 기본 JSON 응답과 묶음 Skill, MCP 도구 제공을 설명한다.[1]
- `mcp-server/`의 Python 서버는 폐기 예정인 이전 경로이며 README는 내장 MCP 서버를 현재 통합 방식으로 구분한다.[1]

## 어떤 기술을 사용하는가?

- `Go`: 확인한 모듈은 Go 1.26.0을 선언하고 Gin, GORM, Redis 및 여러 검색 저장소용 라이브러리를 포함한다.[2]
- `PostgreSQL/pgvector`: 지원되는 의미 검색 저장소이며 Docker Compose와 Kubernetes는 배포 선택지로 제공된다.[1]

## 실제로 어디에 사용할 수 있는가?

- 개인 학습용 공개 PDF와 Markdown 자료를 모아 질문하고, 답변에 인용된 원문을 확인하는 지식 검색에 활용할 수 있다.[1]
- 공개 자료에서 관련 개념의 위키를 생성해 문서 검색과 지식 정리의 차이를 학습할 수 있다.[1]

## 왜 주목할 만한가?

학습 관점에서는 동일한 지식 처리 기반을 검색 답변, 도구 실행, 위키 구성에 재사용하는 설계가 관찰 지점이다.[1]

## 장점

- 모델, 검색 저장소와 파일 저장소를 바꿀 수 있도록 선택지를 제공한다.[1]
- 출처 표시, 문서 조각 수정 이력과 처리 단계 추적을 통해 결과와 처리 과정을 함께 확인할 수 있다.[1]

## 단점 / 주의점

- MIT 라이선스이며 README는 서비스의 인터넷 직접 노출을 피하고 접근 제어와 방화벽을 설정하도록 경고한다.[1]
- README는 샌드박스 명령이 root로 실행되는 변경을 명시하며, 데스크톱 앱 설치 프로그램은 아직 배포하지 않는다고 구분한다.[1]
