## 한 줄 요약

OpenStock은 외부 시장 데이터와 차트를 연결해 종목 검색, 관심 목록, 기업 정보를 보여 주는 공개 주식 정보 웹 앱이다.[1]

## 이 Repository는 무엇인가?

고가 시장 정보 플랫폼의 대안을 목표로 하지만, README는 증권 중개 서비스가 아니며 금융 조언을 제공하지 않는다고 구분한다.[1]

앱은 Finnhub의 데이터와 TradingView의 차트·시장 화면을 조합하고, 사용자 인증과 개인별 관심 목록을 관리한다.[1]

### 자료 확인 범위

2026-09-27에 공개 README와 아래에 인용한 공식 파일을 확인한 기본 초안이다.
설치·실행 시험이나 성능 검증을 한 문서는 아니다.
개인적인 Star 이유와 평가, 사용 후기는 직접 작성할 수 있도록 비워두었다.

## 주요 기능

- 종목 검색과 단축키 검색 창, 사용자별 관심 목록, 기업 프로필·재무·기술 지표 화면을 제공한다.[1]
- 시장 열지도·시세·뉴스를 표시하고, 선택적으로 외부 서비스의 여러 출처 감성 분석 정보를 종목 상세 화면에 연결한다.[1]
- 가입 이벤트를 이용한 AI 맞춤 환영 메일과 일정에 따른 주간 뉴스 요약 발송을 안내한다.[1]

## 어떻게 동작하는가?

```text
사용자가 로그인하고 종목을 검색하거나 관심 목록을 선택한다.
↓
서버 작업과 외부 데이터·차트 연동으로 종목 및 시장 정보를 가져온다.
↓
대시보드·종목 상세 화면에 표시하고 관심 목록을 MongoDB에 저장한다.
```

시세와 뉴스의 원천은 앱 자체가 아니라 외부 제공자이며, 데이터 갱신 방식과 제공자 요금제에 따라 지연과 접근 범위가 달라진다.[1]

### 확인한 파일 구성

- `app/`은 인증·기본 화면·종목 상세와 API 경로를, `components/`는 검색 창·관심 목록 버튼 등 화면 요소를 구성한다.[1]
- `database/`에는 관심 목록 모델과 MongoDB 연결 구성이 있고, `lib/`에는 인증·시장 데이터 서버 작업과 메일·예약 작업 연동이 나뉘어 있다.[1]
- `package.json`에는 Next.js 개발·빌드·서비스 구동, 데이터베이스 연결 검사와 Vitest 테스트 명령이 선언되어 있다.[2]

## 어떤 기술을 사용하는가?

- `Next.js·React·TypeScript`: 페이지와 사용자 화면을 구성하며, Tailwind CSS와 Radix UI 계열 구성요소를 사용한다.[1][2]
- `Better Auth·MongoDB`: 로그인 확인과 사용자 데이터 저장을 맡고, `Finnhub·TradingView`는 시장 데이터와 차트 화면을 공급한다.[1]
- `Inngest·Nodemailer`: 이벤트·예약 작업과 메일 전송에 사용하며, AI 환영 문구에는 별도 모델 API 연결을 안내한다.[1]

## 실제로 어디에 사용할 수 있는가?

- 개인 학습에서 관심 종목을 모아 보고, 데이터 API와 차트 위젯이 하나의 웹 화면으로 연결되는 과정을 살펴볼 수 있다.[1]
- 인증·관심 목록 저장·가입 후 메일 작업을 함께 가진 웹 앱의 구성 사례로 읽을 수 있다.[1]

## 왜 주목할 만한가?

학습 관점에서는 금융 데이터를 직접 생성하기보다 외부 API·위젯과 사용자 데이터 저장을 결합한 통합 앱이라는 점이 핵심이다.[1]

## 장점

- 종목 검색·개인 관심 목록·시장 개요를 같은 앱 흐름에 연결한다.[1]
- 메일 설정을 생략한 로컬 환경에서도 앱을 시작할 수 있다고 설명하여 선택 기능의 의존성을 구분한다.[1]

## 단점 / 주의점

- Node.js 20 이상, MongoDB 연결, Finnhub 키가 필요하고, 무료 데이터의 지연·요청 한도·시장별 위젯 제한이 있다.[1]
- AGPL-3.0을 명시하므로 수정·배포·네트워크 제공 시 소스 제공 등 해당 라이선스 의무를 검토해야 한다.[1]
- `NEXT_PUBLIC_` 환경 변수는 브라우저에 노출된다고 경고하며, ‘실시간’ 소개만으로 모든 시세가 무지연이라고 판단해서는 안 된다.[1]
