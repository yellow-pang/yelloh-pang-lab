## 한 줄 요약

Voicebox는 목소리 프로필, 텍스트 음성 합성과 음성 전사를 한곳에서 다루는 로컬 중심 음성 스튜디오다.
TTS는 글을 말소리로 바꾸는 처리이고 STT는 녹음을 글로 바꾸는 처리다.
새로운 음성 모델 하나를 제공하는 저장소라기보다 여러 엔진, 편집 화면과 API를 연결하는 애플리케이션이다.
README는 에이전트가 MCP로 발화 기능을 호출하는 방식도 소개한다.[1]

## 목소리를 만드는 일과 오디오를 편집하는 일

짧은 대사를 만드는 것과 긴 원고를 자연스러운 오디오로 만드는 것은 다른 문제다.
Voicebox는 참조 녹음에서 프로필을 만들거나 제공되는 목소리를 선택하고, 합성 결과에 효과를 적용하고, 여러 음성을 Stories 시간축에 배치하는 흐름을 제공한다.
같은 앱에 받아쓰기와 전사가 있어 음성의 입력과 출력 양쪽을 다루는 점이 특징이다.[1]

목소리 복제 기능을 읽을 때에는 권리부터 확인해야 한다.
공식 Responsible Use 문서는 자신의 목소리, 발화자의 명시적 허락을 받은 목소리와 적법한 라이선스 자료를 사용하도록 한다.
프로그램이 음성의 소유자를 독립적으로 검증할 수는 없다고도 밝힌다.
따라서 음성 파일을 갖고 있다는 사실만으로 복제와 배포 권한을 얻는 것은 아니다.[2]

## 같은 텍스트라도 엔진의 표현 방식이 다르다

README는 여러 TTS 엔진을 생성마다 선택할 수 있다고 설명한다.
참조 음성 없이 제공 목소리를 쓰는 엔진과 복제 중심 엔진이 있으며 언어 범위도 다르다.
전체 앱이 여러 언어를 지원한다는 설명을 모든 엔진의 동일한 지원 목록으로 해석하면 안 된다.
목소리 프로필과 합성 엔진은 연결되지만 같은 개념은 아니다.[1]

구체적으로 웃음과 한숨 같은 괄호 태그는 Chatterbox Turbo에서만 비언어 표현으로 해석된다고 명시한다.
다른 여러 엔진은 이를 글자로 읽을 수 있다.
자연어 말투 지시와 특수 태그, 생성 후 음높이·잔향 효과도 서로 다른 단계다.
웃는 말투를 원할 때 텍스트에 태그를 넣는 것과 생성된 오디오에 효과를 적용하는 것을 혼동하지 않아야 한다.[1]

긴 텍스트는 문장 경계로 나누어 각 조각을 생성하고 경계에서 소리를 겹쳐 이어 붙이는 crossfade를 사용한다.
README의 ‘무제한 길이’라는 제목 아래에도 입력 최대 문자 수와 조각 크기 설정이 있으므로 문자 그대로 무한한 입력을 받는다고 읽으면 안 된다.
원본 음성, 효과를 적용한 버전과 다른 seed로 재생성한 take의 계보도 구분해 보관한다고 설명한다.[1]

## 예시로 따라가는 흐름

자신의 목소리로 짧은 공개 안내문을 읽는 오디오를 만든다고 가정하자.
이해를 위한 가상 예시이며 직접 실행한 결과가 아니다.
입력은 사용 권리가 있는 참조 녹음, 안내문 텍스트와 선택한 엔진이다.
프로필을 선택해 생성을 요청하면 작업은 대기열에 들어간다.
대표 구현 `task_queue.py`는 각 생성 ID와 실행 작업을 묶고 worker가 하나씩 처리해 GPU 경쟁을 피하도록 한다.
화면에서 다음 원고를 입력할 수 있다는 것과 여러 추론이 동시에 실행된다는 것은 다르다.[1][3]

작업이 끝나면 원본 음성을 듣고 필요한 효과 버전을 만든다.
사람은 발음, 문장 누락, 긴 입력의 연결 지점, 엔진이 특수 태그를 문자 그대로 읽지 않았는지 확인해야 한다.
생성 요청을 취소하는 경우 코드도 대기 중인 작업과 실행 중인 작업을 구분한다.
실행 중이면 해당 task를 취소하고 대기 중이면 취소 표시를 남겨 worker가 건너뛰게 한다.
예외가 발생해 마지막 상태를 쓰지 못했을 때에는 활성 데이터 행을 실패로 바꾸려는 복구 경로가 있다.
따라서 목록에 작업이 생겼다는 것만으로 오디오 완성을 판단하지 말고 최종 상태와 실제 파일을 함께 검토해야 한다.[3]

## 로컬 중심이라는 설명의 적용 범위

README는 모델, 음성 데이터와 녹음을 로컬에 두는 구성을 강조한다.
하지만 API나 MCP를 통해 다른 앱과 연결할 경우 그 앱이 텍스트와 결과를 어떻게 처리하는지는 별도의 경계다.
이 조사에서는 네트워크 통신 전체를 감시하지 않았으므로 모든 가능한 연동에서 데이터가 절대 외부로 나가지 않는다고 검증한 것은 아니다.
로컬 모델 사용과 외부 클라이언트의 데이터 정책을 나누어 확인해야 한다.[1]

배포와 플랫폼 기능도 구별된다.
README는 Linux 사전 빌드 바이너리가 아직 없다고 안내하고, macOS의 접근성 확인을 이용한 자동 붙여넣기를 따로 설명한다.
지원 운영체제 목록이 있다는 사실만으로 모든 네이티브 기능과 설치 편의가 동일한 것은 아니다.
GPU와 모델에 따른 메모리 요구, 최초 모델 준비와 오디오 장치 권한도 실제 사용 전 확인할 대상이다.[1]

합성 음성을 게시할 때에는 요구되는 경우 AI 생성임을 알리고 목소리 사용 동의와 배포 조건을 관리해야 한다.
공식 사용 문서는 무단 사칭, 사기와 음성 인증 우회, 오해를 유도하는 중요 의사소통을 금지한다.
자신의 컴퓨터에서 생성했다는 사실은 다른 사람의 음성을 존중할 책임을 없애지 않는다.[2]

## 정리

Voicebox는 음성 합성·전사·편집을 프로필과 작업 이력으로 묶는 앱이다.
엔진별 표현 차이와 생성 상태를 확인하고, 목소리 사용 권리와 공개 책임은 사용자가 별도로 관리해야 한다.
