## 한 줄 요약

Univer는 웹 앱 안에 스프레드시트·문서 편집 기능을 넣고 화면 없는 문서 처리도 구성할 수 있는 확장형 개발 도구 모음이다.[1]

## 이 Repository는 무엇인가?

완성된 파일 뷰어만 제공하는 것이 아니라 편집 화면과 계산 기능을 직접 조합하는 Office SDK이다.[1]

이 저장소는 공개 핵심 코드와 플러그인을 담으며, 별도 상용 확장인 Univer Pro나 다른 에이전트 연동 프로젝트와 범위를 구별한다.[1]

## 주요 기능

- 기능 단위 확장인 플러그인을 조합하거나, 필요한 플러그인·스타일·API 등록을 묶은 Preset으로 시작할 수 있다.[1]
- 스프레드시트 편집, 수식, 필터·정렬, 데이터 검증과 조건부 서식 등을 공개 기능으로 제공한다.[1]
- 사용하기 쉬운 상위 호출 인터페이스인 Facade API로 통합 문서·셀 범위·수식·명령·이벤트를 다루며 브라우저와 Node.js를 지원한다.[1]

## 어떻게 동작하는가?

```text
문서 종류와 필요한 플러그인 또는 Preset, 언어와 표시 영역을 선택한다.
↓
Univer 인스턴스를 만들고 화면·문서·계산 플러그인과 Facade API를 연결한다.
↓
통합 문서 등을 생성하고 API 또는 편집 화면으로 내용을 읽고 수정한다.
```

위는 README의 웹 스프레드시트 예제 흐름이며, Node.js에서 화면 없이 처리하는 Headless 방식은 UI 구성과 구별되는 사용 경로이다.[1]

### 확인한 파일 구성

- `packages/`에는 핵심 모델·계산 및 표시 엔진·UI와 기능 플러그인이 있고, `presets/`는 미리 정한 조합을 제공한다.[1]
- `examples/`는 로컬 브라우저 개발용 Vite 편집 환경이며, `package.json`은 개발·빌드·검사 명령을 정의한다.[1][2]

## 어떤 기술을 사용하는가?

- `Canvas`: 여러 문서 종류의 편집 내용을 그리는 공통 표시 계층이다.[1]
- `Node.js`: 사용자 화면 없이 문서·통합 문서 처리를 실행하는 환경이다.[1]
- `TypeScript·pnpm·Turbo`: 저장소에 타입 검사와 여러 패키지의 개발·빌드·테스트를 위한 도구로 선언되어 있다.[2]

## 실제로 어디에 사용할 수 있는가?

- 개인 웹 앱에 계산 가능한 표 편집 화면을 넣고 셀 값과 수식을 API로 다루는 학습에 사용할 수 있다.[1]
- 화면 표시와 문서 모델을 나누어 같은 구조를 브라우저와 서버 처리에 활용하는 방식을 살펴볼 수 있다.[1]

## 왜 주목할 만한가?

학습 관점에서는 문서 모델, 계산, 표시와 사용자 조작을 플러그인으로 분리하면서 상위 API로 연결하는 설계가 관찰점이다.[1]

## 장점

- 미리 구성된 조합과 직접 플러그인을 선택하는 방식을 모두 제공한다.[1]
- 공개 기능과 Pro 전용 기능의 경계를 README에서 따로 설명한다.[1]

## 단점 / 주의점

- 공개 SDK는 Apache-2.0이지만 협업, 편집 이력, 파일 가져오기·내보내기, 차트와 피벗 등은 Pro·상용 기능으로 구분한다.[1]
- Sheets가 가장 성숙한 영역이며 Docs·Slides도 같은 구조를 쓰지만 발전 중이라고 설명하므로 모든 문서 유형의 기능을 같다고 볼 수 없다.[1]
- 같은 SDK 배포 계열의 패키지 버전을 맞춰야 하며, 소스 개발 환경에는 Node.js `>=22.18`이 명시되어 있다.[1][2]
