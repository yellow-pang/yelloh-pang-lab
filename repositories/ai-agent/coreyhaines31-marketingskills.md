## 한 줄 요약

marketingskills는 문구 작성, 검색 노출, 전환 개선과 분석 같은 작업을 AI 에이전트가 수행하도록 정리한 마케팅 Skill 모음이다.
광고 플랫폼이나 자체 분석 서비스가 아니라 Markdown 지침과 관련 자료를 제공한다.
핵심은 개별 요청에 답하는 기법뿐 아니라 제품·독자·표현 기준을 여러 작업에서 공유하는 구조다.[1]

## 페이지를 바꾸기 전에 목적부터 정하기

개인 프로젝트 소개 페이지에서 “더 보기 좋게 고쳐 달라”는 요청만 주면 어떤 행동을 늘리려는지 불분명하다.
문서를 읽게 하는 페이지와 체험 신청을 받는 페이지는 같은 수정 기준을 쓰기 어렵다. `cro`는 페이지 종류, 주된 전환 목표, 방문자가 들어온 경로부터 확인하도록 한다.
전환은 방문자가 가입·다운로드 등 목표 행동을 하는 것을 뜻한다.[2]

이 모음은 그런 질문을 작업별 지침으로 나눈다.
문구 작성은 copywriting, 가입 과정은 signup, 가입 후 첫 사용은 onboarding, 실험 설계는 ab-testing으로 연결된다.
비슷한 성장 관련 요청이라도 문제가 발생한 지점에 맞는 Skill을 읽도록 범위를 구분한 것이다.[1][2]

## 공통 맥락은 한 문서에 남긴다

`product-marketing`은 `.agents/product-marketing.md`에 제품 설명과 대상 독자, 해결하려는 문제, 차별점, 표현 어조, 근거와 목표를 정리한다.
다른 Skill은 이 내용을 먼저 확인해 같은 기본 질문을 반복하지 않도록 설계되어 있다.
문서가 없으면 기존 README나 소개 페이지에서 초안을 만들거나 대화로 정보를 모으는 두 경로를 제시한다.[1][3]

자동 초안이라고 해서 내용이 확정되는 것은 아니다.
해당 Skill은 사용자에게 잘못된 점과 빠진 점을 검토받고 수정하도록 명시한다.
고객 표현도 꾸며 쓴 설명보다 실제 문장을 수집하는 데 초점을 둔다.
제품 주장의 근거와 원하는 어조가 같은 문서에 있다고 해서 근거 없는 수치를 사용할 권한이 생기지는 않는다.[3]

기존 문서가 있으면 전체를 다시 묻지 않고 변경할 부분을 정한다.
중요한 저장 때 버전과 변경 이력을 남기는 규칙도 있다.
여러 Skill이 같은 내용을 읽는 만큼 제품 설명 하나가 바뀌었을 때 변경 이유를 추적하려는 구조다.
옛 `.claude/` 경로나 이전 파일명도 확인하고 표준 위치로 옮길지 제안하도록 되어 있다.[3]

## CRO는 진단과 실험을 분리한다

`cro`의 분석은 가치 제안의 명확함에서 시작해 제목, 행동 유도 버튼, 화면의 강조 순서, 신뢰 근거, 사용자의 우려, 불편 요소로 이어진다.
CTA는 방문자에게 다음 행동을 권하는 버튼이나 문구다.
단순히 눈에 띄는 버튼을 만드는 것보다 무엇을 얻는지와 다음 단계가 명확한지 살피는 항목이 포함된다.[2]

페이지별 관점도 다르다.
소개 페이지에서는 처음 온 독자의 이해와 이동 경로를, 가격 페이지에서는 요금제 차이와 선택의 어려움을, 블로그에서는 내용과 관련된 행동 유도를 살핀다.
“모든 페이지의 버튼을 같은 색으로 바꾸기” 같은 일괄 처리가 아니라 목표와 문맥에 맞춰 질문을 바꾸는 지침이다.[2]

출력은 빠르게 바꿀 부분, 더 큰 수정, 시험할 가설, 문구 대안으로 나뉜다.
A/B 테스트는 두 안을 나누어 보여주고 정한 지표로 비교하는 실험이다.
Skill은 일부 아이디어를 사실로 가정하지 말고 시험 대상으로 남기도록 안내한다.
추천 문장이 설득력 있다는 것과 실제 방문 행동이 개선되었다는 것은 다른 판단이다.[2]

## 예시로 따라가는 흐름

오픈소스 개인 도구의 소개 페이지에서 문서로 이동하는 길을 검토하는 이해를 위한 가상 예시이며 직접 실행한 결과가 아니다.
입력은 공개 페이지 주소나 내용, “시작 문서 열기”라는 목표, 독자가 검색 결과에서 들어온다는 맥락이다.
먼저 공통 제품 문서가 있다면 읽고 도구의 대상과 핵심 문제를 확인한다.
없다면 README에서 설명 초안을 만들되 사람이 바로잡을 수 있는 상태로 남긴다.[2][3]

그다음 첫 화면이 도구의 목적을 설명하는지, 제목이 검색해서 들어온 사람의 기대와 맞는지, 문서 버튼이 다른 링크와 경쟁하지 않는지 순서대로 살핀다.
결과는 바꿀 문장과 이유, 더 큰 구성 변경, 실제 이용 데이터로 시험할 가설로 나뉜다.
사람은 추천한 장점이 도구에 실제로 있는지, 사용자 후기나 수치가 확인된 자료인지, 링크가 올바른 문서로 가는지 점검한다.
방문 기록이 없다면 현재 전환율을 추정해서 채우지 않으며, 변경 후 좋아졌다고 미리 결론 내리지 않는다.
여기서 완성되는 것은 검토와 실험을 위한 제안이지 성과를 입증한 보고서가 아니다.[2]

## 설치 범위와 외부 행동의 경계

README는 전체 모음뿐 아니라 특정 Skill을 선택하는 설치 경로도 제공한다.
그러나 지침을 설치하는 작업과 광고 계정·분석 도구에 연결하는 일은 별개다.
외부 시스템을 실제로 수정하려면 해당 도구와 인증, 대상 계정과 비용 범위를 따로 확인해야 한다.
이 글에서 확인한 CRO 파일 자체는 페이지 추천 절차이지 광고 예산을 자동 승인하는 정책이 아니다.[1][2]

이전 버전에서 이름이 바뀐 Skill은 새 폴더와 옛 폴더가 함께 남을 수 있다는 주의도 있다.
현재 README의 이름으로 찾지 못했다고 기능이 없다고 단정하거나, 옛 이름과 새 이름을 별개 기능으로 세면 혼동이 생긴다.
특히 page-cro와 form-cro가 cro로 통합된 관계를 설명하며 공통 제품 문서의 위치 변경도 별도로 안내한다.[1]

MIT 라이선스로 공개된 지침이라는 점은 유료 서비스 연결 비용이나 생성 문구의 사실 확인 책임을 없애지 않는다.
템플릿의 예시 숫자, 후기, 로고를 실제 근거처럼 채우지 말아야 하며, 성과 판단에는 실제 자료가 필요하다.
목적과 대상 독자가 부정확하면 정교한 분석 순서도 잘못된 방향의 제안을 만들 수 있다.[1][2][3]

marketingskills는 마케팅 작업을 공통 맥락과 분야별 절차로 연결한다.
