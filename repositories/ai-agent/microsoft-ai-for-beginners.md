## 한 줄 요약

AI-For-Beginners는 인공지능의 여러 접근법을 설명하고 코드와 과제로 연결하는 공개 교육 과정이다.
완성된 챗봇 서비스나 학습이 끝난 모델을 배포하는 저장소가 아니다.
기호적 AI, 신경망, 이미지와 언어 처리, 강화학습과 윤리 등을 차례로 읽는 강의 자료이며, README는 12주·24개 수업이라는 틀로 소개한다.[1]

## AI를 사용한다는 말에서 한 단계 안으로

이미지를 분류하거나 문장을 처리하는 서비스를 접해도 ‘무엇을 입력으로 주고 어떤 규칙을 학습했는지’는 보이지 않을 수 있다.
이 과정은 제품 사용법보다 AI의 접근법을 구별하는 데 초점을 둔다.
규칙과 지식 표현을 사용하는 방식, 데이터로 가중치를 조정하는 신경망, 이미지·텍스트에 맞춘 구조를 함께 다룬다.[1]

초보자에게 필요한 것은 모든 용어를 한 번에 외우는 일이 아니라, 하나의 작은 분류 문제에서 입력·모델·정답·평가가 어떻게 이어지는지 보는 것이다.
README는 사전 읽기 자료, 설명과 코드가 섞인 Jupyter Notebook, 일부 주제의 실습 과제로 수업을 구성한다.
노트북은 문장으로 읽은 개념과 실제 계산 단계를 같은 문서 안에서 확인할 수 있는 형식이다.
수업 설명만 읽고 노트북을 생략하면 빠지는 이론도 있다고 명시한다.[1]

## 전체 지도를 보고 작은 모델로 내려가기

교육 과정의 신경망 부분은 perceptron에서 다층 구조, 프레임워크, 컴퓨터 비전으로 이어진다.
Perceptron은 입력을 두 부류로 구분하는 간단한 분류 모델이다.
대표 수업은 입력의 여러 특징에 가중치를 적용한 값을 만들고, 그 값에 계단형 함수를 적용해 두 결과 중 하나를 고르는 구조를 설명한다.
가중치는 각 입력이 판단에 얼마나 영향을 주는지 정하는 값이다.[2]

학습은 이미 정답을 아는 예제를 보고 잘못 분류된 경우를 줄이도록 가중치를 바꾸는 과정으로 소개된다.
이때 학습률은 한 번 수정할 때 변화의 크기를 정하는 값이다.
수식을 처음 읽는 독자는 기호 전체를 외우기보다 ‘예측을 한다→정답과 비교한다→틀린 경우가 줄도록 모델을 고친다’는 연결부터 잡을 수 있다.
대표 수업의 설명이 두 종류 구분에서 출발하기 때문에, 이후 여러 숫자를 구별하는 과제가 왜 별도로 필요한지도 드러난다.[2]

전체 README에는 PyTorch와 TensorFlow 계열의 노트북이 함께 제시된다.
이는 두 라이브러리를 한 프로그램에서 반드시 결합하라는 뜻이 아니라 같은 주제를 다른 구현 도구로 볼 수 있는 경로다.
수업은 최소 한 버전의 노트북을 따라 읽으라고 안내하며, 일부 항목은 별도 실습이나 외부 학습 모듈로 이어진다.[1]

## 예시로 따라가는 흐름

대표적인 읽기 사례는 perceptron 수업에서 손글씨 숫자 분류 과제로 넘어가는 경로다.
먼저 수업에서 ‘두 숫자 사이의 구분’이라는 문제를 읽고, 실습 README에서 이를 모든 숫자 구분으로 확장하는 요구를 확인한다.
과제의 입력은 MNIST 손글씨 숫자 데이터이며, 목표는 주어진 이미지가 어떤 숫자인지 판단하는 분류기를 구성하는 것이다.
이는 공식 과제의 흐름을 설명한 것으로 직접 학습하거나 정확도를 측정한 결과는 아니다.[2][3]

실습은 각 숫자에 대해 ‘이 숫자인가, 나머지 숫자인가’를 구별하는 이진 분류기를 만들라고 제안한다.
숫자별 perceptron들의 가중치를 행렬로 묶어 한 입력에 대한 여러 출력을 얻고, 그중 가장 큰 출력을 고르는 `argmax`로 최종 숫자를 정하는 힌트도 제공한다.
여기서 행렬은 여러 가중치 묶음을 표처럼 정리한 계산 구조다.
최종 결과물에는 학습 데이터와 시험 데이터의 정확도, 그리고 어떤 숫자를 어떤 숫자로 잘못 읽었는지 보여 주는 혼동 행렬이 요구된다.
독자는 정확도 하나만 보는 대신 자주 혼동되는 숫자 쌍과 두 데이터 집합의 결과 차이를 확인하도록 안내받는다.[3]

## 수업 자료와 검증된 코드의 차이

이 교육 과정이 다루지 않는 주제도 README에 명확하다.
고전적 머신러닝 전반, 깊은 수학, 특정 클라우드 프레임워크 사용법, 완성형 대화형 AI 서비스 구축은 별도 자료로 안내한다.
따라서 과정 제목의 ‘초보자용’을 모든 사전 지식과 환경 문제가 제거되었다는 뜻으로 받아들이기보다, 주제의 입구와 범위가 정리되어 있다는 의미로 읽는 편이 정확하다.[1]

대표 perceptron README의 Python 조각에는 그대로 실행 가능하다고 단정하기 어려운 부분도 있다.
가중치를 리스트로 초기화한 뒤 `weights.shape`를 갱신식에 사용하는 표현이 보인다.
이 글에서는 해당 코드를 실행하지 않았으며 정상 동작 예제로 복사해 제시하지 않는다.
개념 수식, 설명용 조각, 연결된 노트북을 구별하고 실제 실습 시에는 입력 타입과 갱신식을 확인해야 한다.[2]

README 자체도 최신 신경망 구조를 다루지만 최첨단 내용을 충분히 반영하지 못할 수 있다고 밝힌다.
따라서 학습 순서를 얻는 자료와 특정 시점의 최신 성능·최신 API 문서를 구분할 필요가 있다.
한국어를 포함한 번역 링크가 있다는 사실도 원문의 코드와 설명에 대한 검토를 대신하지 않는다.[1]
