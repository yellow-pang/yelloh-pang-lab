## 한 줄 요약

prompts.chat은 AI 대화에 사용할 프롬프트를 발견·공유·수집하는 자료집이자 자체 호스팅 가능한 웹 애플리케이션이다.
예전 이름은 Awesome ChatGPT Prompts이며, 현재 README는 여러 대화 모델에서 활용할 프롬프트와 웹·CLI·MCP·플러그인 접근 경로를 소개한다.
새로운 모델을 제공하거나 모든 프롬프트의 결과를 보증하는 프로젝트는 아니다.[1]

## 좋은 요청을 다시 찾을 수 있게 만들기

AI에게 설명을 다듬거나 인터뷰 연습을 부탁할 때 매번 역할과 출력 형식을 처음부터 적을 수 있다.
하지만 한 번 쓴 요청을 다시 활용하려면 어디에 저장했는지, 어떤 조건에서 썼는지, 무엇을 바꿀 수 있는지 알아야 한다.
prompts.chat은 이런 요청 문장을 이름과 분류가 있는 자료로 탐색하게 한다.[1][2]

프롬프트는 모델에게 주는 입력 지침이다.
역할, 처리할 내용, 답변 형식과 대화 순서를 적을 수 있지만 그 문장이 도구 권한이나 실제 실행 환경을 만들어 주지는 않는다.
자료 안의 “터미널처럼 답하라”는 요청과 실제 운영체제에서 명령을 실행한 결과는 특히 분명히 구분해야 한다.[3]

## 자료 파일과 운영되는 사이트

README는 웹 탐색 외에 `prompts.csv`와 `PROMPTS.md`를 제공하고, 사이트에 추가된 프롬프트가 저장소로 동기화된다고 설명한다.
추가 확인한 CSV의 열은 역할 이름인 `act`, 본문인 `prompt`, 개발자 관련 표식, 유형, 기여자다.
같은 프롬프트를 사람이 찾아 읽는 경로와 프로그램이 행 단위 데이터로 다루는 경로가 함께 있는 셈이다.[1][3]

CSV에는 줄바꿈과 따옴표가 들어 있는 본문도 있다.
파일의 한 물리적 줄을 곧 한 프롬프트라고 가정하기보다 CSV 형식으로 읽어야 한다.
예를 들어 Job Interviewer 항목은 역할·대기 규칙·시작 문장이 하나의 본문 필드 안에 들어 있다.
데이터 구조를 먼저 알면 프롬프트의 일부를 다른 항목으로 잘못 읽는 일을 줄일 수 있다.[3]

자체 호스팅 안내는 분류·태그·의미 검색, 비공개 프롬프트, 변경 기록과 수정 요청 같은 기능을 소개한다.
의미 검색은 정확히 같은 단어가 없어도 뜻이 가까운 항목을 찾는 방식이다.
단순히 텍스트 파일을 복사하는 용도와 계정·검색·수정 이력을 가진 개인 자료 서비스를 운영하는 용도를 나누어 볼 수 있다.[2]

## 에이전트가 자료를 찾는 경로

Claude Code 플러그인은 프롬프트와 Skill 검색 명령을 제공한다.
문서에는 키워드·분류·태그·유형 검색, 변수 치환을 포함한 프롬프트 가져오기, 새 프롬프트 저장, 개선 기능이 나뉘어 있다.
Skill 검색은 관련 파일을 함께 가져오거나 설치하는 경로까지 설명한다.[4]

찾아 읽는 작업과 계정에 저장하는 작업도 구분된다.
저장에는 API 키가 필요하다고 명시되며, Skill의 파일 추가·수정·삭제 도구도 소개한다.
따라서 플러그인을 단순 검색창이라고만 이해하면 쓰기 기능의 범위를 놓칠 수 있다.
공개 프롬프트를 얻은 뒤 어떤 프로젝트 파일에 반영할지는 사용자가 별도로 확인할 대상이다.[4]

## 예시로 따라가는 흐름

대표 자료는 공식 CSV의 `Job Interviewer` 항목이다.
이 프롬프트는 모델을 면접관, 사용자를 지원자로 정하고 `${Position:Software Developer}`라는 자리에서 직무를 지정한다.
전체 면접 대화를 한 번에 써 달라는 요청이 아니라 질문을 하나씩 하고 답을 기다리라고 반복해서 명시하며, 시작 문장으로 “Hi”를 제시한다.[3]

읽는 순서는 역할 설정, 직무 변수, 응답 범위, 대기 규칙을 분리하는 것이다.
사용자는 연습할 직무를 선택하고 프롬프트를 자신이 사용하는 모델에 전달할 수 있다.
기대하는 결과는 질문과 사용자 답변이 번갈아 이어지는 연습 대화이지, 실제 채용 담당자의 평가나 합격 가능성 예측이 아니다.
사람이 확인할 부분은 질문이 해당 직무와 수준에 맞는지, 한 번에 여러 질문을 쏟아내지 않는지, 제공한 경험을 왜곡하지 않는지다.
실제 개인정보나 공개할 수 없는 내용을 넣지 않고도 일반적인 연습은 구성할 수 있다.
이 글에서는 모델에게 프롬프트를 실행하지 않았고 질문·평가 결과도 만들어 제시하지 않는다.[3]

같은 파일의 Linux Terminal 항목과 비교하면 차이가 더 선명하다.
이 항목은 명령을 실제로 실행할 도구를 설정하는 코드가 아니라 터미널 출력처럼 답하라는 텍스트다.
이런 답변을 실행 증거로 오인하면 존재하지 않는 파일이나 성공하지 않은 명령을 믿게 될 수 있다.
자료집은 요청 표현을 참고하는 곳이지 실행 사실을 제공하는 기록은 아니다.[3]

## 공개 데이터와 사적인 사용의 경계

README의 라이선스 설명은 소스 코드와 사이트 작성 콘텐츠에는 MIT, 프롬프트 콘텐츠와 데이터에는 CC0를 적용한다고 나눈다.
과거의 단순 CC0 소개만 보고 전체 애플리케이션까지 같은 조건이라고 적으면 이 구분을 놓친다.
재사용할 대상이 데이터인지 코드인지 먼저 확인해야 한다.[1]

자체 호스팅에는 Node.js와 PostgreSQL, 인증 설정 등이 필요하며 의미 검색용 API 키도 선택 설정으로 소개된다.
자기 서버에 자료집을 둔다고 외부 모델로 보낸 프롬프트나 검색 요청까지 기기 안에만 남는 것은 아니다.
어떤 AI 기능을 켰는지와 연결된 공급자의 데이터 처리 범위를 별도로 확인해야 한다.[2]

또한 커뮤니티 추천과 투표는 개별 프롬프트가 모든 모델에서 정확하다는 실험 결과가 아니다.
역할 지시가 강하더라도 모델의 지식·도구·안전 제한은 그대로 적용된다.
전문 영역의 답변이나 계산·실행 결과는 해당 근거와 실제 도구로 확인할 필요가 있다.[1][3]

## 정리

prompts.chat은 재사용 가능한 요청 문장을 찾고 관리하는 자료 기반을 제공한다.
프롬프트를 실행 능력이나 정확성 보증으로 받아들이지 않고, 데이터 재사용과 계정 저장·호스팅의 경계를 구분해야 한다.
