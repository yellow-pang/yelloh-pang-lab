## 한 줄 요약

Cline은 사용자의 개발 요청을 받아 코드 읽기·수정·명령 실행을 수행하며 IDE, 터미널과 데스크톱에서 사용할 수 있는 코딩 Agent이다.[1]

## 이 Repository는 무엇인가?

Agent는 답변만 작성하는 대신 도구로 작업을 수행하는 AI 소프트웨어이며, Cline은 파일 변경과 터미널 작업을 그 중심에 둔다.[1]

공통 엔진을 CLI, 편집기 확장과 데스크톱 앱에 연결하고 SDK를 통해 별도 Agent와 도구 통합을 만들 수 있도록 제공한다.[1]

### 자료 확인 범위

2026-09-27에 공개 README와 아래에 인용한 공식 파일을 확인한 기본 초안이다.
설치·실행 시험이나 성능 검증을 한 문서는 아니다.
개인적인 Star 이유와 평가, 사용 후기는 직접 작성할 수 있도록 비워두었다.

## 주요 기능

- 여러 파일의 관계를 읽어 함께 수정하며 편집 차이와 체크포인트를 통해 변경 내용을 검토하거나 되돌릴 수 있다.[1]
- Plan 모드에서 조사와 계획을 수행하고 Act 모드에서 실행하며, 승인 방식 또는 자동 승인을 선택할 수 있다.[1]
- 프로젝트 규칙, 필요할 때 읽는 Skill, SDK 플러그인과 MCP 외부 도구 연결로 작업 방식을 확장한다.[1]

## 어떻게 동작하는가?

```text
작업 폴더와 사용할 모델을 정하고 개발 요청을 전달한다.
↓
프로젝트를 살펴 계획한 뒤 승인 정책에 따라 파일 수정과 명령 실행을 진행한다.
↓
변경 차이, 명령 출력과 체크포인트를 확인하며 결과를 검토한다.
```

README의 대화형 코딩 흐름을 요약한 것이며, 사용자 개입 없는 CLI 실행이나 자동 승인에서는 매 단계 수동 승인을 전제로 할 수 없다.[1]

### 확인한 파일 구성

- `package.json`은 `sdk/packages/*`, `apps/*` 등을 묶는 작업 공간과 공통 빌드·검사 명령을 선언한다.[2]
- `sdk/`는 프로그래밍용 Agent API를, `apps/cli/`는 터미널 UI와 비대화형 실행을 담당한다고 README가 설명한다.[1]
- `apps/examples/desktop-app/`은 Tauri 외곽 앱, Bun 보조 프로세스와 Next.js UI로 구성된 데스크톱 앱 경로이다.[1]

## 어떤 기술을 사용하는가?

- `Bun`과 `TypeScript`: 여러 패키지의 개발·빌드·형식 검사에 사용되며 루트 manifest는 Bun과 Node.js 엔진 조건을 선언한다.[2]
- `MCP`: 데이터베이스와 외부 API 같은 도구를 Agent에 연결하는 확장 경로이다.[1]

## 실제로 어디에 사용할 수 있는가?

- 개인 학습 프로젝트의 여러 파일을 함께 수정하고 변경 차이를 검토하는 코딩 보조 도구로 활용할 수 있다.[1]
- CLI의 구조화 출력, 예약 실행과 SDK 도구 등록을 통해 반복적인 코드 점검 자동화 방식을 학습할 수 있다.[1]

## 왜 주목할 만한가?

학습 관점에서는 공통 Agent 엔진과 여러 사용자 인터페이스를 분리하면서 계획·실행 모드와 승인 정책을 함께 제공하는 구조가 관찰 지점이다.[1]

## 장점

- 여러 모델 제공자와 로컬 모델 연결을 지원해 하나의 제공자만 전제하지 않는다.[1]
- 변경 검토·되돌리기와 명시적 실행 승인을 작업 흐름 안에 제공한다.[1]

## 단점 / 주의점

- README는 Apache 2.0 라이선스를 안내하지만 JetBrains 플러그인 소스는 현재 공개하지 않는다고 명시하므로 모든 클라이언트 소스가 이 저장소에 있다고 보면 안 된다.[1]
- 명령 실행은 패키지 설치나 배포까지 포함할 수 있고 자동 승인을 켤 수 있으므로 실행 권한과 승인 범위를 구분해야 한다.[1]
