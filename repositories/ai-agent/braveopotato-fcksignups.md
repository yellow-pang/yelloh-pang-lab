## 한 줄 요약

이 저장소는 README에서 NoSignups라는 이름으로 소개되는 브라우저 도구 디렉터리다.
계정 생성 없이 사용할 수 있는 공개 도구를 모아 검색·분류하는 React·TypeScript 웹 프로젝트이며, 목록에 있는 모든 도구의 기능을 자체 구현하는 프로그램은 아니다.
저장소 식별자는 기존 `BraveOPotato/FckSignups`를 유지한다.[1]

## 작은 작업 앞에 가입 절차가 끼어들 때

이미지 한 장의 크기를 줄이거나 문서 데이터를 보기 좋게 바꾸려는 상황에서 서비스 가입부터 요구받으면 원래 작업보다 준비가 길어진다.
이 프로젝트는 바로 브라우저에서 사용할 수 있는 도구를 모으는 방향을 제시하고, 기여 조건에도 계정을 만들지 않고 작동해야 한다는 기준을 적어 둔다.
독자는 개별 제품을 일일이 찾는 대신 용도별 후보를 탐색할 수 있다.[1]

다만 디렉터리의 소개와 각 도구의 실제 동작은 다른 확인 대상이다.
README의 무가입·무추적 지향은 이 프로젝트가 밝힌 원칙이다.
항목에 올라 있다는 사실만으로 연결된 모든 외부 사이트의 현재 정책, 데이터 전송, 모든 기능의 무료 이용까지 확인된 것은 아니다.
도구를 찾는 단계와 그 도구에 파일을 맡기는 단계 사이에는 추가 확인이 필요하다.[1][2]

## 목록 데이터와 검색 화면의 역할

README는 도구 항목을 고유 ID, 이름, 한 문장 설명, URL, 분류로 정의하고 태그·소스 저장소·라이선스 같은 부가 정보를 설명한다.
실제 `tools.json`에는 분류와 도구 배열이 들어 있으며, Excalidraw, Squoosh, JSON Crack처럼 서로 다른 목적의 항목이 같은 데이터 형식으로 기록되어 있다.
도구를 소개하는 정보와 외부 도구의 실행 링크가 분리된 구조다.[1][2]

추가 확인한 `useTools.ts`는 데이터를 읽고 검색어와 분류로 목록을 좁히는 코드를 담는다.
검색 대상은 도구 이름, 설명, 태그이며 여러 검색어가 있으면 각 단어가 모두 맞는 항목을 남긴다.
검색어는 소문자 영문·숫자 중심으로 분리한다.
자연어 질문의 뜻을 AI가 해석하는 검색이 아니라 문자열 조건으로 후보를 고르는 구현이다.[3]

목록은 추천 항목과 편집자 선택, 나머지 기준 충족 항목으로 나뉜다.
README도 featured는 편집자의 고유성 판단에 따른 주관적 배치라고 설명한다.
추천 구역이나 Star 값을 안전성 인증이나 절대적 품질 순위로 받아들이기보다는 후보 탐색을 돕는 표시로 읽는 편이 정확하다.[1][3]

화면 쪽 `App.tsx`는 검색과 분류 상태를 `useTools`에서 받고, 필터 컴포넌트와 도구 표시 컴포넌트에 전달한다.
이 구조에서 디렉터리는 사용자 입력에 맞는 소개 항목을 보여 주는 역할을 맡고 실제 압축이나 그림 편집은 연결된 도구가 맡는다.
입력 상태, 필터 결과, 외부 서비스 사이의 경계가 코드에 드러난다.[4]

## 예시로 따라가는 흐름

사진 파일을 줄일 도구를 찾는 상황을 살펴보자.
이해를 위한 가상 예시이며 직접 실행한 결과가 아니다.
사용자는 목록에서 media 분류를 선택하고 `image compression`을 검색한다고 가정한다.
확인한 데이터에서 Squoosh는 media 분류이고, 설명에 이미지 크기를 여러 형식으로 줄이는 도구라는 문장이 있으며 태그에도 이미지와 압축 관련 단어가 있다.
따라서 이 항목의 소개 정보와 검색 조건을 어떻게 연결하는지 코드로 따라갈 수 있다.[2][3]

처리 과정은 선택한 분류에 맞는 도구를 남기고, 검색 단어가 이름·설명·태그에 포함되는지 검사한 뒤, 해당 항목을 화면용 목록으로 전달하는 순서다.
사용자가 얻는 결과는 압축된 파일이 아니라 Squoosh의 이름·설명·외부 URL·소스 링크 같은 후보 정보다.
사진을 넣고 결과물을 만드는 작업은 디렉터리를 떠나 해당 도구에서 일어난다.
이번 조사에서는 외부 도구에 사진을 올리지 않았으며 실제 압축률을 확인하지 않았다.[2][4][3]

사람이 확인할 부분은 파일 형식 지원, 처리 장소, 외부 전송 여부와 해당 서비스의 최신 사용 조건이다.
목록에 기록된 라이선스 값도 원 프로젝트의 현재 라이선스와 대조해야 한다.
이렇게 읽으면 무가입 도구를 발견하는 도움과, 데이터를 맡겨도 되는지 결정할 책임이 섞이지 않는다.
특히 개인 사진이나 비공개 자료는 도구 목록의 짧은 소개만 보고 업로드를 결정하지 않는 편이 안전하다.

## 검색과 데이터 갱신에서 보이는 제약

영문·숫자 중심의 검색어 분리 규칙은 한국어 질의 해석기가 아니다.
한글만 입력했을 때 기대한 의미 검색이 이루어진다고 볼 수 없으므로, 데이터에 실제 들어 있는 영문 태그나 제품명으로 확인하는 편이 코드의 동작에 맞다.
또한 도구 설명이나 태그가 부정확하면 검색 결과도 그 기록의 한계를 그대로 따른다.[3]

데이터를 불러오지 못하면 코드가 준비된 대체 데이터를 사용하고 최신 데이터를 얻지 못했다는 오류 상태를 설정한다.
화면에 목록이 나타났다는 사실과 최신 목록을 성공적으로 받았다는 사실은 구별해야 한다.
이 글은 저장소의 수집본을 읽었으므로 웹사이트의 실시간 목록이나 각 링크의 가용성을 검증했다고 주장하지 않는다.[3]

라이선스도 두 층으로 나뉜다.
README는 디렉터리 코드가 GPL-3.0이며, 목록에 있는 각 도구는 각자의 라이선스를 유지한다고 명시한다.
디렉터리의 공개 조건을 외부 도구 전체에 적용하거나, 소스 링크가 있다는 이유만으로 동일한 이용 조건이라고 해석하면 안 된다.[1]

## 정리

NoSignups는 가입 부담 없이 쓸 도구를 찾도록 돕는 디렉터리다.
사용자는 구조화된 소개와 검색으로 후보를 좁힐 수 있지만, 실제 데이터 처리와 이용 조건은 연결된 각 도구에서 따로 확인해야 한다.
