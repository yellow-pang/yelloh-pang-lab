## 작은 언어 모델의 학습 과정을 열어 보는 프로젝트

MiniMind는 작은 언어 모델의 구조와 학습 코드를 공개하고, 사전학습부터 지시 미세조정과 여러 후속 학습까지 설명하는 프로젝트다.
이미 있는 모델에 질문하는 응용 앱만이 아니라, 모델이 데이터를 보고 가중치를 바꾸는 과정을 직접 읽을 수 있는 교육용 구현과 자료를 함께 제공한다.
README는 핵심 알고리즘을 PyTorch의 기본 구성으로 작성해 높은 수준의 추상화 뒤에 숨기지 않는다는 방향을 설명한다.[1]

큰 모델은 파일을 내려받는 것부터 많은 메모리가 필요하고, 학습 코드는 복잡한 프레임워크 호출로만 보일 수 있다.
MiniMind는 작은 규모로 핵심 단계를 추적할 수 있게 하는 접근이다.
작은 모델을 학습할 수 있다는 사실과 큰 서비스 수준의 지식·추론 능력을 얻는다는 주장은 구별해야 한다.
이 저장소의 중요한 읽기 대상은 결과 모델뿐 아니라 데이터와 학습 반복문, 저장과 평가 경로다.[1]

## 사전학습과 지시 미세조정은 다른 역할이다

사전학습은 텍스트의 다음 부분을 예측하면서 언어의 패턴을 익히는 과정이고, SFT는 질문과 응답 같은 예시를 통해 지시를 따르는 형태로 조정하는 과정이다.
README의 빠른 학습 경로는 사전학습 데이터를 준비해 가중치를 얻고, 이어 SFT로 별도 가중치를 만드는 순서다.
사전학습만 끝냈다고 완성된 대화 도우미가 되는 구조가 아니다.[1]

LoRA, 선호 학습, AI 피드백 기반 강화학습, 도구 호출 등은 추가 경로로 소개된다.
LoRA는 전체 가중치를 모두 수정하는 대신 작은 추가 가중치를 학습하는 방식이고, 선호 학습은 더 나은 응답을 고르는 신호를 반영하는 과정이다.
처음 읽을 때 모든 기법을 같은 학습 명령의 옵션으로 생각하기보다 어떤 데이터와 목표를 쓰는 별도 단계인지 구별하는 편이 낫다.[1]

대표 코드인 `trainer/train_pretrain.py`의 반복문은 데이터 로더에서 입력 토큰과 정답을 받아 장치에 옮기고 모델의 손실을 계산한다.
손실은 예측과 정답의 차이를 나타내는 학습 신호다.
이어 역전파로 어느 가중치를 어떻게 바꿀지 계산하고, 일정한 누적 주기마다 최적화기를 적용한다.
코드에는 학습률 조정, 기울기 제한, 로그와 주기적 저장도 직접 드러나 있다.[2]

## 예시로 따라가는 흐름

공식 README의 빠른 재현 경로는 `pretrain_t2t_mini.jsonl`과 `sft_t2t_mini.jsonl`을 데이터 폴더에 준비하는 데서 시작한다.
JSONL은 한 줄마다 하나의 JSON 기록을 담는 형식이다.
사전학습 스크립트가 데이터를 읽어 반복 학습하면 `out/pretrain_*.pth` 형태의 가중치를 저장하고, 다음 SFT 단계는 `out/full_sft_*.pth` 형태의 결과를 만든다고 설명한다.
이후 평가 스크립트에서 어떤 가중치를 사용할지 지정한다.[1]

이 흐름은 명령을 실행한 기록이 아니라 공식 안내와 사전학습 코드를 연결해 읽은 것이다.
코드의 일반 가중치 저장과 재개용 체크포인트는 목적도 다르다.
일반 파일은 모델 상태를 저장하고, 재개 경로는 최적화기와 진행 상태 같은 정보를 포함해 중단 지점부터 이어가기 위한 기반을 남긴다.
사람은 학습이 끝났다는 로그만 보지 말고 사용한 데이터, 모델 차원, 가중치 이름과 평가 입력이 서로 맞는지 확인해야 한다.
학습 손실이 내려가도 사실성이 좋아졌는지, 데이터의 문장을 외웠는지, 대화 형식이 맞는지는 별도 평가가 필요하다.[2]

## 작은 반복문 안에서 관찰할 수 있는 선택

사전학습 코드에는 `accumulation_steps`가 있다.
이는 작은 묶음에서 계산한 기울기를 여러 번 모아 한 번에 가중치를 갱신하는 방식이다.
메모리에 올리는 한 묶음과 실제 갱신 주기를 분리해 읽으면 왜 모든 반복에서 최적화기가 움직이지 않는지 이해할 수 있다.
기울기를 제한하는 코드와 혼합 정밀도 관련 scaler도 보이므로 학습은 손실을 계산하는 한 줄로 끝나지 않는다.[2]

저장할 때는 분산 학습의 대표 프로세스인지 확인하고 모델을 평가 모드로 바꾼 뒤 가중치를 저장하고 다시 학습 모드로 돌아간다.
여러 장치에서 실행할 가능성이 코드 구조에 반영되어 있다는 뜻이지, 이번 환경에서 다중 GPU 학습을 확인했다는 뜻은 아니다.
설정값과 실행 조건을 기록해야 다른 학습 결과와 비교할 수 있다.[2]

## 시간·비용 문구의 조건을 놓치지 않기

README의 ‘2시간’과 ‘3위안’은 전체 학습 과정을 모든 장비에서 완료한다는 약속이 아니다.
주석은 단일 NVIDIA 3090에서 SFT 한 epoch를 실행한 저자의 측정 시간과 해당 GPU 대여 비용이라고 설명한다.
Epoch는 학습 데이터를 한 차례 도는 단위다.
사전학습, 추가 학습, 데이터 준비와 평가까지 포함한 보편적인 총비용으로 옮겨 적으면 범위가 달라진다.[1]

README는 CUDA가 없을 때 CPU나 MPS를 선택할 수 있어도 속도와 호환성이 크게 다를 수 있다고 경고한다.
또한 주선 모델 구조와 토크나이저가 바뀌는 이력도 있어 예전 가중치와 새 코드의 호환성을 당연시할 수 없다.
실제 실행 전에는 데이터·가중치·코드의 조합을 맞추고, 외부 학습 기록 서비스를 사용할 경우 무엇이 전송되는지 확인해야 한다.[1]

## 정리

MiniMind는 작은 언어 모델을 통해 데이터가 가중치와 응답으로 이어지는 과정을 공개한다.
간결한 구현을 읽는 것, 실제로 학습을 재현하는 것, 얻은 모델의 능력을 검증하는 것은 각각 다른 단계다.
