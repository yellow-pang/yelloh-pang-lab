# Repository 기록

GitHub에서 발견하거나 Star한 Repository를 조사하고 분석한 문서를 저장합니다. 새 문서는 [`templates/repository.md`](../templates/repository.md)를 복사한 뒤 Repository의 성격에 맞는 카테고리에 저장합니다.

## 카테고리

- `ai-agent/`: AI Agent와 Agent 기반 개발 도구
- `browser-automation/`: 브라우저 제어와 자동화
- `developer-tools/`: 개발 생산성과 개발 환경을 위한 도구
- `frontend-design/`: Frontend, UI, UX, 디자인 관련 도구
- `backend-infra/`: Backend, 서버, 운영 환경, Infra 관련 도구
- `ai-ml-data/`: AI, Machine Learning, 데이터 처리와 분석
- `system-design/`: Software Architecture와 System Design

문서 파일명은 Repository 이름을 기준으로 kebab-case를 사용합니다. 날짜는 파일명에 넣지 않고 Front Matter의 `created`에 기록합니다.
